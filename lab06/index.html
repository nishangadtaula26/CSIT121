Labs 1 & 2

Published on October 1, 2026 by Nishan Gadtaula

In the first two labs, I learned about the basics of HTML and how webpages are created. I learned that HTML uses different elements to organize information on a webpage. I also learned about HTML syntax rules and conventions.

What I Learned

  1. I learned how to create a basic HTML webpage.
  2. I learned how to use HTML tags and semantic elements.
  3. I learned about internal and external links.

Some HTML topics that I learned are:

  • HTML headings and paragraphs
  • Ordered and unordered lists
  • Hyperlinks
  • HTML header and footer

Lab 3

Published on October 3, 2026 by Nishan Gadtaula

In lab 3, I learned about CSS and how to style HTML pages. I learned to create external CSS and link it to our HTML file. I understood how to style different elements.

What I Learned

  1. I learned about Internal, External and Inline CSS.
  2. I learned about class, id, element and descendant selectors.
  3. I learned how to combine multiple selectors in a single CSS rule.

Best Design Practices

Published on November 6, 2026 by Nishan Gadtaula

In this lab, I learned about responsive web design and how to make a webpage work on different devices. I learned that a good website should be easy to read, simple to navigate, and organized properly. I also learned how media queries help change the layout based on screen size.

What I Learned

  1. I learned how to use CSS Grid to create columns.
  2. I learned how to use media queries for different screen sizes.
  3. I learned how to use navigation links to move between blog posts.
